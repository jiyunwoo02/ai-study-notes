강점 — 잘 지킨 것들
모든 주장에 출처 표시 Schema 핵심 18개 페이지 전체에서 사실 주장마다 (출처: 파일명.md) 형식을 일관되게 유지했다. 출처 없이 단정 짓는 문장이 단 한 건에 그쳤다(multi-head-attention.md 64차원 계산값).
기존 페이지를 갱신하는 ingest 패턴 준수 관찰 포인트 통과 02·03번 ingest 시 self-attention.md가 새로 만들어지지 않고 기존 페이지에 병합됐다. Schema의 핵심 관찰 포인트를 올바르게 수행했다. 각 ingest마다 frontmatter의 sources 목록도 함께 확장해 추적 가능성을 유지했다.
충돌 발생 시 임의 판정 없이 ⚠️ 섹션으로 명시 Schema 핵심 05번 회의록이 기존 위키와 충돌하는 두 지점(Transformer 발표 연도, FlashAttention 특성)을 모두 탐지하고, 어느 쪽이 맞는지 판정하지 않은 채 출처와 신뢰도를 함께 제시했다. 미검증 구두 발언과 논문 스터디 노트를 신뢰도 차원에서 명확히 구별한 점도 돋보인다.
모르는 내용은 "자료에 없음"으로 명시 MQA와 GQA는 04번 자료에서 키워드만 등장하고 상세 내용이 없었는데, 추측하거나 채워 넣지 않고 "자료에 없음. 키워드만 언급됨"이라고 명확히 적었다. 05번의 GQA 액션 아이템("지은이 조사 예정")까지 연결해 미완료 지식임을 표시했다.
개념 간 양방향 링크 연결 [[페이지명]] 링크를 통해 sparse-attention ↔ self-attention, flashattention ↔ tiling ↔ recomputation, kv-cache ↔ mqa ↔ gqa 등 개념 그래프가 체계적으로 형성됐다. 한 방향만 링크하는 단방향 고아 관계가 거의 없다.
log.md · index.md 매 ingest마다 갱신 5번의 ingest 모두에서 ingest 이력(날짜, 파일명, 생성·갱신 목록)을 log.md에 기록하고 index.md의 목차를 최신 상태로 유지했다.
05번 자료의 출처 신뢰도를 메타데이터로 표현 회의록이라는 출처 유형("구두 발언·미검증")을 소스 요약 페이지 상단에 경고로 명시하고, 충돌 표에서 신뢰도 열을 추가해 독자가 판단 근거를 확인할 수 있게 했다.

고아 페이지 concepts/transformer.md index.md에서만 도달 가능하고, self-attention·multi-head-attention·positional-encoding 등 Transformer를 직접 언급하는 개념 페이지 어디에서도 [[transformer]] 링크가 없다. 개념 그래프에서 고립되어 있다.

05번 ingest 특이사항 — 가장 어려운 케이스

05번은 "검증 안 된 구두 발언" 출처로, 실습 전체에서 가장 까다로운 케이스였다. 아래 항목들을 올바르게 처리했다.

  • 출처 신뢰도 차별화 — 소스 요약 상단에 "구두 발언·미검증" 경고를 명시하고 충돌 표에 신뢰도 열을 추가했다.
  • 충돌 2건 모두 탐지 — 발표 연도와 FlashAttention 특성 충돌을 각각 해당 개념 페이지에 ⚠️ 섹션으로 표시했다.
  • 일치하는 KV Cache 내용은 보강 — 충돌 없는 내용(KV Cache 메모리 병목)은 kv-cache.md에 "스터디 그룹 확인 사항"으로 추가했다.
  • 액션 아이템을 미완료 지식과 연결 — "GQA 자료 조사" 액션 아이템을 기존 gqa.md의 "자료에 없음" 상태와 연결했다.
