# Wiki Schema (LLM이 따라야 할 운영 규칙)

## 역할
너는 이 위키의 편집자다. `raw/`의 자료를 읽고 `wiki/`의 마크다운 페이지를 만들고 갱신한다.

## 절대 규칙
1. `raw/` 폴더의 파일은 **절대 수정하지 않는다.**
2. 모든 위키 페이지는 한국어로 작성한다.
3. 모든 주장에는 근거가 된 raw 파일명을 `(출처: 01-xxx.md)` 형식으로 적는다.
4. 확인되지 않은 내용을 지어내지 않는다. 모르면 "자료에 없음"이라고 적는다.

## 폴더 구조
- `wiki/index.md`: 전체 페이지 목차 + 한 줄 설명
- `wiki/sources/`: 원본 파일별 요약 페이지
- `wiki/concepts/`: 개념별 페이지 (예: self-attention.md)
- `wiki/log.md`: 어떤 자료를 언제 반영했는지 기록

## 페이지 형식
- 맨 위에 YAML frontmatter: `title`, `type`(source/concept), `sources`(근거 파일 목록)
- 다른 페이지는 `[[페이지명]]` 링크로 연결한다.

## 자료를 반영(ingest)할 때 할 일
1. 해당 자료의 요약 페이지를 `wiki/sources/`에 만든다.
2. 등장한 개념의 페이지를 만들거나, 이미 있으면 **기존 내용에 병합**한다.
3. 기존 위키 내용과 **충돌하는 주장**이 있으면 페이지 안에 `⚠️ 충돌` 섹션을 만들어 두 주장과 각 출처를 함께 적는다. 어느 쪽이 맞는지 임의로 정하지 않는다.
4. `index.md`와 `log.md`를 갱신한다.
