주제: **Transformer 어텐션과 효율화** (원본 5개)

## 폴더 구성
```
llm-wiki-practice/
├── raw/        # 📄 원본 자료 (LLM이 수정하지 않음)
├── wiki/       # 🧠 LLM이 채워갈 빈 폴더
├── schema.md   # 📋 위키 운영 규칙
├── README.md   # 이 문서
└── ANSWER_KEY.md  # 🔒 실습 후에 열어보세요 (스포일러)
```

## 준비물
- 파일 시스템에 접근할 수 있는 LLM 도구 (Claude Code, Cursor 등)
- 또는 Obsidian으로 이 폴더를 vault로 열고 LLM에게 파일을 붙여넣는 방식

## 실습 순서

### Step 1. 규칙 읽히기
> `schema.md`를 읽고 이 위키의 규칙을 요약해줘. 이해했으면 시작할 준비가 됐다고 말해줘.

### Step 2. 자료 1개씩 반영하기 (순서대로)
> `raw/01-attention-is-all-you-need-notes.md`를 schema.md 규칙에 따라 위키에 반영해줘.

01 → 02 → 03 → 04 → 05 순서로 하나씩 반영해 보세요. 한꺼번에 넣지 말고 **하나 넣을 때마다 wiki/ 폴더가 어떻게 바뀌는지** 관찰하는 게 핵심이에요.

### Step 3. 질문하기
> 위키만 참고해서 답해줘. 어텐션의 O(n²) 문제를 해결하려는 접근들을 비교해줘.

> FlashAttention과 Longformer의 차이는?

### Step 4. 점검(lint)하기
> wiki/ 전체를 검토해서 서로 모순되는 내용, 출처가 없는 주장, 연결이 빠진 페이지를 찾아줘.

### Step 5. 답 맞춰보기
`ANSWER_KEY.md`를 열어 LLM이 함정을 잡아냈는지 확인하세요.
